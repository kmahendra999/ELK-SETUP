**Step1: create instance.yml file which we will use in generate certificate.**

*Created this file: in elk1 for save password*

*Created this file for make an* `instances.yml` *file.*  
`root@elk1:/usr/share/elasticsearch`

`root@elk1:cat instances.yml`

instances:

```
- name: "elasticsearch-1"
  dns:
    - "elk01.elkdomainname.com"
- name: "elasticsearch-2"
  dns:
    - "elk02.elkdomainname.com"
- name: "elasticsearch-3"
  dns:
    - "elk03.elkdomainname.com"
- name: "elasticsearch-4"
  dns:
    - "elk04.elkdomainname.com"
```

**Step2: Generate certificate on same node where instace.yml file is there.**

`Cd /usr/share/elasticsearch/`

`sudo bin/elasticsearch-certutil ca --pem`

*keep output file default when ask just hit enter do not give any value.*

`sudo apt install zip unzip -y`

`sudo unzip elastic-stack-ca.zip`

`sudo /usr/share/elasticsearch/bin/elasticsearch-certutil cert --ca-cert ca/ca.crt --ca-key ca/ca.key --pem --in instances.yml --out kibana-https.zip`

`sudo unzip -d certs kibana-https.zip`

`cp -r ca/ca.crt certs/elasticsearch-1/`

`cp -r ca/ca.crt certs/elasticsearch-2/`

`cp -r ca/ca.crt certs/elasticsearch-3/`

`cp -r ca/ca.crt certs/elasticsearch-4/`

**In node 1 to 3 - Step3:** **In Elasticsearch nodes** **Copy certificates files to** `/etc/elasticsearch/certs/` and change the group of folders `chgrp -R elasticsearch /etc/elasticsearch/certs/`

**In node 4 -** **In Kibana nodes** **- Copy certificates files to** `/etc/kibana/certs/` and change the group of folders `chgrp -R kibana /etc/kibana/certs/`
