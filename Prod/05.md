**IN ELK1 :**

`systemctl daemon-reload`

`systemctl enable --now elasticsearch`

After put command and hit enter in anther window open

`tail -f /var/log/elasticsearch/prod-monotoring.log`

So, live we can see if any issue.

**IN ELK2:**

`systemctl daemon-reload`

`systemctl enable --now elasticsearch`

**IN ELK3:**

`systemctl daemon-reload`

`systemctl enable --now elasticsearch`

**Now checking the installation of Elasticsearch service :**

Now after done all check in browser (if 9200 port opened)

`https://elk01.elkdomainname.com:9200`

login with elastic user and password you will get from Step 2 we created the file pass.txt.

**Your output should be like above given step.**

Same you can try with command If your port 9200 is not opened in public.

`curl -u elastic:$ELASTIC_PASSWORD -k` [`https://`](https://es01:9200/)`elk01.elkdomainname.com`[`:9200`](https://es01:9200/)

`curl -u elastic:$ELASTICPASSWORD -k` [`https://`](https://es01:9200/)`elk01.elkdomainname.com`[`:9200/_cat/nodes`](https://es01:9200/)

`curl -u elastic:$ELASTICPASSWORD -k` [`https://`](https://es01:9200/)`elk01.elkdomainname.com`[`:9200/_cat/health`](https://es01:9200/)
