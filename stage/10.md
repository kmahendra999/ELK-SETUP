**Note:** the token in the screenshot above is a dummy sample. Your own token will look the same — a long `AAEAAW...` string — and Kibana shows it **only once**, so copy it immediately and store it somewhere safe. Use your own value in place of the dummy token shown in the install command below.

then in next step you will get code which you need to run on fleet server on shell.

![](/ss01.jpg)

From above code we deployed and run this command on the fleet server.

***make sure for the certificate path which we created earlier else it will not work.***

`curl -L -O https://artifacts.elastic.co/downloads/beats/elastic-agent/elastic-agent-8.14.3-linux-x86_64.tar.gz`

`tar xzvf elastic-agent-8.14.3-linux-x86_64.tar.gz`

`cd elastic-agent-8.14.3-linux-x86_64`

`sudo ./elastic-agent install --url=https://192.168.0.123:8220 --fleet-server-es=https://192.168.0.123:9200 --fleet-server-service-token=AAEAAWVsYXN0aWMvZmxlZXQtc2VydmVyL3Rva2VuLUVYQU1QTEU6RFVNTVktVE9LRU4tUkVQTEFDRS1XSVRILVlPVVJT --fleet-server-policy=fleet-server-policy --fleet-server-es-ca-trusted-fingerprint=0b01e1d9675705f155999393fa1567caac10f9ac5c1f561d3577dcda918cbbd3 --certificate-authorities=/root/fleet/ca.crt --fleet-server-cert=/root/fleet/fleet.crt --fleet-server-cert-key=/root/fleet/fleet.key --fleet-server-port=8220`

Enter Y if ask for yes while installing package.

on Shell output should be Enrolled successfully in last. Else there was something mistake please recheck and rerun the command.
