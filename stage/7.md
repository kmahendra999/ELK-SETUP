**Note on the three `encryptionKey` values above:** these are secrets, not fixed settings — generate your own and never copy them from any document. Each is a 32 character hex string, for example `a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6`. Generate all three at once with:

`/usr/share/kibana/bin/kibana-encryption-keys generate`

Use the **same** three values on every Kibana node in the cluster, but a **different** set per environment (stage vs Prod). Keep them out of Git — if they leak, rotate them (see the Kibana docs for the `encryptedSavedObjects` key rotation procedure, since changing that one without rotating makes existing saved objects unreadable).

`elasticsearch.password` is the `kibana_system` password from the reset-password step below, e.g. `pX9mK2vQ7nB4tR6wL1zY`.

`systemctl enable --now kibana`

If you do not have password of this user kibana\_system

`/usr/share/elasticsearch/bin/elasticsearch-reset-password -u kibana_system`
