Make a folder anywhere.

Keep two files in that.

First ca.crt we had while generated certificate before

Copy that and rename that as ca\_bundle.crt

Second in the same folder create a file linux-installation-script.sh

Replace the dummy token in the script below with the enrollment token you copied from the Linux Servers policy in the previous step. It is a base64 string ending in `==`, for example `RXhhbXBsZUVucm9sbG1lbnRUb2tlbjpSRVBMQUNFLU1F==`. This token lets any host join your Fleet, so treat it as a password and never commit it.

```
#!/bin/bash

# Define variables for fleet_url and token
fleet_url="https://192.168.0.123:8220"
token="RXhhbXBsZUVucm9sbG1lbnRUb2tlbjpSRVBMQUNFLU1F=="
certificate="ca_bundle.crt"
# Function to check telnet connectivity
function check_telnet {
 local host="$1"
 local port="$2"
 nc -z "$host" "$port" &> /dev/null
}

# Verify telnet connectivity to the specified domains
if check_telnet "192.168.0.123" "8220" && check_telnet "192.168.0.123" "9200"; then
 echo "Telnet connectivity to domains is successful."
else
 echo "Telnet connectivity to one or both domains failed. Exiting."
 exit 1
fi

# Download and install Elastic Agent
echo "Downloading Agent..."
curl -L -O https://artifacts.elastic.co/downloads/beats/elastic-agent/elastic-agent-8.14.2-linux-x86_64.tar.gz
echo "Extracting Agent..."
tar xzvf elastic-agent-8.14.2-linux-x86_64.tar.gz
cp $certificate elastic-agent-8.14.2-linux-x86_64
cd elastic-agent-8.14.2-linux-x86_64
echo "Installing Agent..."
# Get the current working directory and store it in a variable
current_path=$(pwd)
sudo ./elastic-agent install --url="$fleet_url" --enrollment-token="$token" --certificate-authorities="$current_path/$certificate"
```

Now Copy these both files in a folder.

Copy folder to a machine which machine you want to monitor using elk stack.

Run the linux script using root user.

*(root user recommended – so it can collect the logs properly.)*
